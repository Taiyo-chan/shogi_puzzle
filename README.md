# 王将出陣（おうしょうしゅつじん）- Web Edition

名作将棋スライディングパズル**「王将出陣」**（古典パズル「箱入り娘」の将棋アレンジ版）をブラウザで美しく快適に遊べるWebアプリケーションです。

---

## 📖 また今度遊びたくなったときの手順（マニュアル）

### 🌟 方法1：ダブルクリックで起動（一番かんたん・おすすめ！）

Finderでこのフォルダ（`osho_shutujin`）を開き、中にある
👉 **`起動する.command`**
を**ダブルクリック**してください。

1. 自動でターミナルが開き、ローカルサーバーが立ち上がります。
2. 自動でブラウザが開き、すぐにゲーム画面（`http://localhost:5173`）が表示されます。

---

### 💻 方法2：ターミナルから起動する場合

ターミナルアプリを開いて、以下のコマンドをコピー＆ペーストして実行してください。

```bash
cd ~/Desktop/osho_shutujin
npm run dev
```

コマンド実行後、ブラウザで以下のURLを開いてください：
👉 **http://localhost:5173**

---

### 🛑 遊び終わったときの終了方法

* **方法1（ダブルクリック起動時）**：開いたターミナルウィンドウの「×」ボタンを押して閉じるだけで終了できます。
* **方法2（ターミナル操作時）**：ターミナル上で **`Ctrl + C`** キーを押すとサーバーが停止します。

## 🎮 ゲームのルールと目的

### 目的
盤面の最奥部（下側中央）に鎮座する**「王将」**を、敵陣最前線にある**上部の出陣口（開口部）**から盤外へと脱出（出陣）させることが目的です。

- **公式最短手数**：**81手**
- **動かし方**：駒を持ち上げたり飛び越えることはできません。空いているスペースに縦横にスライドさせて移動させます。
- **出陣できるのは王将のみ**：金将、銀将、飛車、角行、桂馬、香車、歩兵は枠の外に出してはいけません。

## ✨ 主な機能と特徴

1. **極上の和モダンデザイン**
   - 榧（かや）調の美しい将棋盤と漆塗り駒の面取り立体デザイン
   - 毛筆フォント（Noto Serif JP）と金箔・朱色のアクセント
   - レスポンシブ対応（PC・タブレット・スマートフォンの縦画面でも快適に操作可能）

2. **快適な操作性**
   - **ドラッグ & スワイプ**：マス目に吸い付くスムーズなスライド移動（スマホ対応）
   - **ワンタップ移動**：動ける方向が1つなら自動スライド。複数ある場合は選択矢印を表示
   - **キーボードショートカット**：`[U]` 一手戻す / `[R]` 最初から / `[H]` ヒント

3. **リアルな音響効果 (Web Audio API)**
   - 将棋盤に響く乾いた「パチッ」という心地よい着手音
   - 駒を滑らせる木肌の擦れ音
   - 出陣成功時の拍子木・重低音の和太鼓サウンド（ミュート切替対応）

4. **高速AIソルバー（幅優先探索 BFS）搭載**
   - **ヒント機能**：現在の盤面から最短で出陣するための「次の1手」を即座にハイライト
   - **神業再生（デモ）**：初期配置から最短81手（または現在の盤面から）AIが自動で駒を動かして出陣する手順を鑑賞可能
   - **速度切替機能**：**`0.25x`（超スロー）** / **`0.5x`（ゆっくり）** / **`1x`（標準）** / **`2x`（高速）** / **`4x`（超速）**

5. **充実の難易度ステージ**
   - **本陣：王将出陣（上級・81手）**：公式クラシック初期配置
   - **初陣：出陣の刻（初級・15手）**：初心者向けの練習配置
   - **前哨戦：包囲突破（中級・35手）**：中盤の打開力を試す配置
   - **激闘：盤上の攻防（上級・55手）**：本格的な難関配置
   - **最高記録保存**：最小手数・最速タイムをローカルストレージに自動記録
   - **祝賀演出**：出陣達成時の桜吹雪・金箔パーティクルと段位・称号判定

## ❓ トラブルシューティング

* **Q. 画面が真っ白、または接続できない**
  * ターミナルで `npm run dev` が動いているか確認してください。
  * 別のアプリがポート5173を使っている場合は、ターミナルに表示されるURL（例: `http://localhost:5174` 等）にアクセスしてください。
* **Q. 効果音が鳴らない**
  * 画面右上の「効果音」ボタンが「消音中」になっていないかご確認ください。
  * ブラウザの仕様上、画面内で一度駒を動かすかクリックすると音が有効化されます。
